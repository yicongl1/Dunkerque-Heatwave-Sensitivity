# 1. 研究现状（État de l'art，约 5 页）

## 1.1 热浪、酷暑与气候变化

**热浪（canicule）**指连续至少三天、昼夜温度均异常偏高的天气过程；持续时间更长、空间范围更广时称为**酷暑（vague de chaleur）**。对健康起决定作用的并非白天最高温，而是**夜间没有缓解**：当最低气温不再下降，人体无法恢复，2003 年法国约 1.5 万人死亡的超额死亡正是由此产生（2018、2019、2022、2023 年重复出现）。

气候变化并不"制造"热浪，但它**提高了频率、强度和持续时间**。对规划者而言，问题因此发生转移：不再是"这个城市会不会遇到热浪"，而是"**当热浪来临时，它有多缺乏准备**"。

## 1.2 城市热岛（ICU）：定义与机制

**城市热岛**指城市与其周边乡村/自然环境之间的温差。该差值通常为正（城市更热），**夜间最大**，在静风晴朗的夜晚可达 5–10 °C。它不等于广义的"城市高温"，也不是全球变暖本身：它是一个**局地的、由城市形态和材料造成**的现象。

其机制是叠加的：

**a) 辐射平衡与反照率。** 沥青、混凝土、瓦、锌板的反照率低（0.05–0.20，而草地约 0.20–0.30），因此吸收而非反射大部分太阳辐射。能量以热量形式储存在材料本体中，夜间缓慢释放——这正是热岛峰值出现在夜间的直接原因。

**b) 地表不透水化。** 人工化地表无法通过土壤蒸发散失能量。自然地表上，净辐射有相当比例转化为**潜热**（蒸散）；在不透水地表上，它几乎全部转化为**显热**，即气温升高。这是街区尺度上最具决定性的因子。

**c) 植被减少。** 植被通过两条路径起作用：**遮荫**（在阳光到达地面前截获辐射）与**蒸腾**（把能量转化为水汽）。移除树冠等于同时移除两者。反之，新建公园或连续林荫道会形成**局部冷岛**，其强度随距离衰减。

**d) 人为热。** 交通、工业、供暖、空调、照明、工业流程——所有终端能耗最终都以热量形式散逸到城市大气中。对敦刻尔克这样以工业和港口为主的城市，这一项并非次要，某些地段甚至是首要贡献者。

**e) 城市形态与街谷效应。** 两侧高楼夹峙的窄街通过多次反射截留辐射，并削弱通风：热量难以排出。**建筑密度**、**街道高宽比**与走向决定夜间通风质量。

**f) 地形与近水性。** 冷空气密度大，在低洼处积聚；开阔地形则有利于冷空气下沉流动。水体起**温度调节**作用：热惯性大，可蒸发，因此有局部降温效果，但作用半径通常只有数百米。

## 1.3 加剧因子与缓解因子

| 因子 | 对气温的作用 | 方向 | 量级 / 说明 |
|---|---|---|---|
| 不透水率 | ↑ 显热 | 加剧 | 街区尺度主导因子 |
| 建筑密度与高度 | ↑ 储热、↓ 通风 | 加剧 | 街谷效应，夜间尤甚 |
| 材料反照率 | ↑ 吸收 | 加剧 | 深色屋顶与路面 |
| 交通、工业、空调 | ↑ 人为热 | 加剧 | 高度局地、强度大 |
| 树冠覆盖 | ↓ 到达地面的辐射，↑ 潜热 | 缓解 | 效果随距离衰减 |
| 草地/裸土 | ↑ 蒸发 | 缓解（中等） | 弱于树冠 |
| 水体、湿地 | ↑ 热惯性，↑ 蒸发 | 缓解 | 邻近效应 |
| 风、地形开阔 | ↑ 换气 | 缓解 | 随夜晚条件变化 |
| 能源贫困、年龄、健康状况 | ↑ 脆弱性（非气温） | 社会性加剧 | 决定死亡率而非热岛强度 |

这一区分至关重要：**一个地区的敏感性不只是物理的，也是社会的**。树荫充足的低密度住区里的热岛，与老年人口集中、保温差的密集住区里的热岛，后果完全不同。

## 1.4 热浪对城市的影响

- **健康**：脱水、中暑、心肺功能失代偿；超额死亡集中在 75 岁以上、婴幼儿、独居者与户外劳动者。
- **舒适度与公共空间使用**：高温时段硬质广场与街道无法使用，步行与自行车出行条件恶化。
- **能源**：夏季用电峰值（空调），电网承压，并形成**正反馈**——空调把热量排到街上，加剧热岛。
- **空气质量**：高温强日照促进对流层臭氧生成；热浪与大气污染叠加在同一人群上。
- **水与土壤**：蒸发加剧、土壤干化、城市植被水分胁迫——在最需要遮荫降温时，植被反而失去降温能力。
- **城市生态系统**：树木在水分胁迫下衰退，日常生物多样性下降。

## 1.5 如何用 GIS 评估一个地区的敏感性？

任务书提出两条硬性约束：**不得使用气象数据**（分析对象是地区的**特征**，而不是气温），**不得使用现成的图层**（不允许直接使用已制作好的热岛图层或 LCZ 图层）。因此必须**从原始图层自行构建指标**。

三类方法：

**a) 矢量途径（邻近性与构成分析）**
- 对冷源（公园、水体）与热源（干道、工业区）做**多环缓冲区**；
- 用**空间连接**把植被占比、到水体的距离等赋予每栋建筑/每个街区；
- 用**字段计算**（面积、密度、比值）与**属性选择**构建逐要素指标；
- 用**联合（Union）/相交**交叉两套分区（例如 IRIS × 土地利用）。

**b) 栅格途径（面状分析）**
- **矢量→栅格**转换（建筑、植被、水体）；
- **核密度（Kernel Density）**：把带权重的对象点集转换为连续的强度面——这是"影响随距离衰减"这一想法最直接的数学表达；
- **欧氏距离 + 重分类**：构建邻近性梯度；
- **地图代数**（Raster Calculator、`Con`、`Reclassify`）：把多个图层合成为一个指数；
- **分区统计**：把指数按 IRIS 或市镇汇总。

**c) 网络途径（本项目未采用）**
网络分析（通行时间、到冷岛的步行可达性、救援路径）对热浪议题高度相关，但本项目因时间原因未做，是已识别的改进方向之一（见 §4.3）。

**本项目的选择**：结合**矢量**与**栅格**两个模块，既满足"至少使用两个本学期模块"的要求 [C]，也契合现象本身——建筑、植被、水体是离散对象，但它们的影响是连续场。

## 1.6 为什么要把 GIS 与多准则分析（AMC）结合？

GIS 擅长回答"在哪里""有多少"，却不擅长回答"**综合考虑，到底有多严重**"。AMC 恰好补上这一步聚合：

- 它把所选准则及其权重**显式化**，从而可被讨论、被质疑；
- 它把单位不同的图层（建筑密度 m²/m²、植被密度、水体密度）**归一化**到同一尺度 [0;1]；
- 它生成**可制图的综合指数**，进而分级（极弱→极强）；
- 它允许**敏感性分析**：如果把植被权重加倍，结论会变吗？

经典做法是**加权求和**（Weighted Overlay / Raster Calculator）：

$$S = \sum_{i=1}^{n} p_i \cdot c_i^{*} \quad \text{且} \quad \sum p_i = 1$$

其中 $c_i^{*} \in [0;1]$ 为归一化准则，$p_i$ 为其权重。权重可由**两两比较（Saaty 的 AHP）**或专家判断确定。AHP 要求一致性：一致性比率 CR 应小于 0.10。

**常见陷阱**：把"加剧型"与"缓解型"准则直接相加而不反号。缓解型准则（植被、水体）必须先**取反**（$1 - c^{*}$），否则植被越多，算出的敏感性反而越高。

## 1.7 方法的局限

- **无法用气温验证**：任务书禁止使用气象数据，因此指数无法率定。它是**相对敏感性指标**，不是气温图。
- **权重的任意性**：任何一组权重都是选择，必须论证并做检验。
- **尺度效应**：栅格像元大小（本例 33–44 m）与核密度搜索半径在很大程度上决定结果。
- **数据不完美**：BD TOPO 描述的是建筑轮廓，并非处处都有材料与真实高度；CORINE 土地利用粗糙（最小制图单元 25 ha）。
- **缺少时间维度**：指数是静态的，不反映真实暴露（户外停留时间、行为习惯）。

# 3. 敏感性分析（约 10 页）

## 3.1 目标与假设

**目标**：构建敦刻尔克市镇的**热敏感性地图**，把三种空间效应——建筑致热、植被降温、水体降温——聚合为**综合敏感性指数**，并分为五级。

**工作假设**（报告中必须明确写出）：

- **H1**：对象（建筑、树、水体）的热效应**与其占地面积成正比**，并**随距离衰减**——这正是"以面积加权的核密度"所表达的内容。
- **H2**：在市镇尺度上各效应**可加**：综合指数是三个归一化效应的加权和。
- **H3**：建筑是**加剧型**，植被与水体是**缓解型**；后者在求和前必须取反。
- **H4**：在没有气温数据（题目禁止）的前提下，所得指数是**相对**的：它用于区域之间比较，不能预测摄氏度。

## 3.2 使用数据

所有图层均为 **RGF93 / Lambert 93**（EPSG:2154），单位为米——等角投影，是面积与距离有意义的前提 [C，已在 `.prj` 与 `ProjetV2.mxd` 中核对]。

| 图层 | 几何类型 | 来源 | 数量 | 用途 |
|---|---|---|---|---|
| `Batiment` | 面 | BD TOPO (IGN) | **43 912** | 建筑轮廓、高度、户数、层数、性质 |
| `Vegetation` | 面 | BD TOPO / 城市绿地地籍 | **1 131** 个区域 | 植被覆盖（林地、公园、行道树） |
| `VegetationPoint` | 点 | 派生（`Feature To Point`） | 1 131 点 | 密度计算载体 |
| `Eau` | 线 | BD TOPO 水系 | 254 段 | 水系网络 |
| `Hydro` | 线 | BD TOPO | 307 | 水系细节 |
| `Reservoir` | 面 | BD TOPO | **626**（含 `VOLUME`） | 蓄水池、水面、水库 |
| `Estran` | 面 | BD TOPO | 53 | 潮间带 |
| `LimiteDeMer` | 线 | BD TOPO | 64 | 海陆分界 |
| `Communes` | 面 | ADMIN EXPRESS (IGN) | 3 789 个市镇 | 行政边界、人口 |
| `Dunkerque` | 面 | 由 `Communes` 截取 | 1 | 研究范围（掩膜） |
| `ConsomationElectrique` | 面（IRIS） | Enedis / 开放数据，经 Excel 连接 | **42 个 IRIS** | 总/平均用电、面积、密度 |
| `Cimetiere`、`TerrainDeSport`、`Construction` | 面 | BD TOPO | 15 / 89 / 43 | 背景与潜在冷源 |
| CLC 1990/2000/2006/2012 | 面 | CORINE Land Cover (AEE) | 4 期 | 人工化演变的历时分析 |

**电力消费图层带来了什么。** 它不是气温数据，而是**人为热**与**能源脆弱性**的代理变量。属性表含 `conso_tota`、`conso_moye`、`part_therm`、`superficie`、`residences`、`taux_de_chomage`，以及两个计算字段 `Aire` 与 `Densité_conso` [C]。因此流程是：

1. 以 IRIS 代码在 **Excel 中完成连接**（属性表 ↔ 消费数据）；
2. 计算每个 IRIS 的面积（`Calculate Geometry`）；
3. 计算**消费密度** = `conso_totale / superficie`（`Field Calculator`）；
4. 用分级符号/比例符号制图。

这就是任务书明确要求的"原始数据 → 指标"的转换。

## 3.3 数据准备

地理数据库 `EffetDataBase.gdb` 中保留的处理链 [C]：

```
Batiment ──► (清理, Union) ──► BatiUnion ──► BatiPoint ──► BatiKer1 ──► BatiKer2 ──► BatiEffet
Vegetation ─► VegetationPoint ─────────────────────────────► VegeKer1 ──► VegeKer2 ──► VegeEffet
Reservoir / Eau / Hydro ──► EauBuffer ──► ZoneEau ──► EauPoint ► EauKer1 ──► EauKer2 ──► EauEffet
                                   ResPoint, HydroPoint ───────────────┘
BatiEffet + VegeEffet + EauEffet ──► EffetEns  (综合栅格)
```

实际完成的步骤 [C]：

1. **投影**：全部图层统一到 Lambert 93，并检查叠加是否正确（部分图层原为 WGS84 或扩展 Lambert，无法与底图对齐）；
2. **融合**：对建筑做 `Union`，消除 BD TOPO 中的重复与重叠；
3. **面转点**（`Feature To Point`）：每个轮廓生成一个点，使每个对象**只贡献一次**，避免密度被对象自身大小扭曲；
4. **计算面积**并写入属性表（作为权重字段）；
5. **核密度计算**，以面积为 `Population Field`，做**两次不同搜索半径**的计算；
6. **两次结果组合**，得到随距离衰减的强度场，再**归一化**；
7. **按市镇掩膜裁剪**（`Extract by Mask` / `Clip`），排除邻市镇"外溢"影响；
8. **三效应聚合**为综合栅格 `EffetEns`。

**为什么做两次核密度？** 单一核密度得到的是"钟形"面，无法区分**贴身处**强度与**远距离**强度。用**小半径核**（刻画紧邻对象的强烈局部效应）与**大半径核**（刻画弥散影响）组合，可得到**梯度**：近处强、远处弱——这正对应任务表述（"离植被越远，降温越弱"）[D——逻辑在对话中有据，具体参数未保存]。

> **需重新确定的参数**：搜索半径（m）、核函数（quartic/gaussian）、输出像元大小。实际输出像元为 **35.5 m**（建筑）、**33.5 m**（植被）、**44.4 m**（水体）[C，读自 `.tfw`]。三者不一致，是**必须修正的缺陷**（组合前应先重采样到统一网格）。

## 3.5 三个梯度的构建

### 3.5.1 建筑热效应

- **输入**：`BatiPoint`（43 912 点），权重 = 轮廓面积。
- **处理**：Kernel Density 两次 → `BatiKer1`、`BatiKer2` → `BatiEffet`。
- **裁剪**：`Dunkerque` 掩膜。
- **解读**：数值为**面积加权的建筑占地密度**（m² 建筑 / m² 地表，经平滑）。值越高，该像元"承载"的建筑越多，储热与放热越强。

### 3.5.2 植被降温效应

- **输入**：`VegetationPoint`（1 131 点），权重 = 植被区域面积。
- **处理**：Kernel Density 两次 → `VegeKer1`、`VegeKer2` → `VegeEffet`。
- **解读**：预期降温强度，在植被中心最大，**随距离衰减**——这正是要求的形态（"像高程图一样，越靠近植被温度越低"）。

### 3.5.3 水体降温效应

- **输入**：`EauBuffer` → `ZoneEau` → `EauPoint`（并对水库用 `ResPoint`、对水系用 `HydroPoint`）。
- **处理**：水面先做**缓冲区**再转点，使大型港池按其真实占地权重参与，而非被当作单个点。
- **结果**：`EauKer1`、`EauKer2` → `EauEffet`。

## 3.6 中间结果 — 统计值

| 栅格 | 像元 | 最小值 | 最大值 | 均值 | 标准差 |
|---|---|---|---|---|---|
| `Impact Thermique des Batiments1.tif` | 35.5 m | 0 | 0.0619 | 0.00754 | 0.01070 |
| `Effet de Rafraîchissement1.tif`（植被） | 33.5 m | 0 | 0.01902 | 0.00438 | 0.00446 |

**三点直接结论：**

1. **建筑占主导。** 建筑热效应最大值（0.0619）是植被降温最大值（0.0190）的 **3.3 倍**，是水体（0.00113）的 **55 倍**；均值之比为 **1.7 : 1**（对植被）与 **51 : 1**（对水体）。
2. **植被是真实但局地的平衡项。** 其均值（0.00438）相对建筑并不可忽略，但最大值很低：敦刻尔克**不存在**能够平衡密集市中心的成片大型绿量。
3. **水体在市镇尺度上降温很弱。** 尽管有 7.8 % 内陆水域和大量水系，实测效应比建筑**低两个数量级**：水体集中（港池），影响不外溢。

**分布特征。** 三幅直方图（256 级）均呈**明显右偏**：少数像元承载了绝大部分强度，多数像元接近零。这反映了一个"源高度集中"的地区，其间大片过渡表面（道路、荒地、空置港区）不被任何一类源"照亮"。

## 3.7 综合敏感性指数（AMC）

### 3.7.1 归一化

三个栅格单位与量级均不同。在市镇范围内做**极差归一化**：

$$c^{*} = \frac{c - c_{min}}{c_{max} - c_{min}} \in [0;1]$$

### 3.7.2 缓解型准则取反

建筑为加剧型，植被与水体为缓解型：

$$B^{*} = c^{*}_{bati} \qquad V^{*} = 1 - c^{*}_{vege} \qquad E^{*} = 1 - c^{*}_{eau}$$

### 3.7.3 权重

权重通过**两两比较**确定，依据三条论据：(i) 建筑是热岛的物理主因；(ii) 植被是地方政府最主要的可操作杠杆；(iii) 水体虽真实存在，但在敦刻尔克空间上边缘化（§3.6 的统计已证实）。

| 准则 | 方向 | 建议权重 | 论证 |
|---|---|---|---|
| 建筑密度 | 加剧 | **0.50** | 主导因子；78 % 人工化；最大值是植被的 3.3 倍 |
| 植被缺乏 | 缓解 | **0.33** | 主要操作杠杆；覆盖碎片化（3.3 % + 2.9 %） |
| 水体缺乏 | 缓解 | **0.17** | 效应真实但极局地（最大值比建筑低两个数量级） |
| **合计** | | **1.00** | |

> **[待补]** 原报告使用的确切权重未能保留。以上是可辩护的重建；若能找回原始数值应予以替换，否则应作为明确的方法学选择写入报告。

### 3.7.4 综合公式

$$S = 0{,}50 \cdot B^{*} + 0{,}33 \cdot V^{*} + 0{,}17 \cdot E^{*}$$

$$S = 0{,}50 \cdot c^{*}_{bati} + 0{,}33 \cdot (1 - c^{*}_{vege}) + 0{,}17 \cdot (1 - c^{*}_{eau})$$

实现方式：`Raster Calculator`（地图代数），在三幅栅格重采样到**统一网格**后计算（见 §3.3 指出的缺陷）。

### 3.7.5 分级

综合栅格 `EffetEns` 按 **5 级**（极弱、弱、中等、强、极强）用**自然断点（Jenks）**分级——适用于右偏分布，因为它最大化类间方差、最小化类内方差。

> **值得一试的变体**：用**显著阈值**而非统计方法分级，使分级对决策者有意义（如"建筑主导且无植被补偿的区域"）。这也正是课程中关于制图分级（discrétisation）的要点：不要分太多类、不要产生空类、断点要可读。

## 3.10 文字分析：这个地区告诉我们什么

**1. 它首先是工业城市，其次才是居住城市。** 39 % 的用地为工业与交通网络，使敦刻尔克的画像相当特殊：人为热的主要来源不是居民交通，而是**工业流程**（钢铁、石化、能源生产）与港口活动。这在方法上有直接后果：常规的降温政策（街道绿化、校园去硬化）**不足以应对**，还必须处理工业余热——那属于与工业企业的协议范畴，而非单纯的空间规划。

**2. 植被碎片化，因此效率低。** 1 131 个植被区域，但人工绿地仅 3.3 %、灌草 2.9 %：覆盖是**破碎的**。而降温效率取决于绿块的**规模**与**连通性**（一个大公园的作用半径远大于一排行道树）。`VegeEffet` 印证了这一点：高值呈点状，很快衰减。**连续的绿蓝网络**比若干微型空间的叠加更有效。

**3. 水：一种虚假的丰裕。** 7.8 % 内陆水域、626 处水面、密集水系——但实测效应比建筑低 50 倍。原因有二：(i) 水体**集中于港池**，远离居住区；(ii) 水体降温是**局地**的，不外溢。因此水体并非全市尺度可调动的杠杆，除非在密集街区**新增近距离水景**——那是规划建议，不是地图结论。

**4. 社会脆弱性未被物理指数覆盖。** 敏感性指数是**物理**的，而超额死亡取决于**脆弱性**：年龄、独居、能源贫困、住房质量。按 IRIS 分析用电量开辟了路径：单位面积用电高、住房老旧、失业率高的 IRIS 同时具备**暴露**与**脆弱**。本项目未把这一交叉做到底——这是最主要的深化方向（§4.2）。

**5. 动态趋势不利。** 人工化仍在推进（74.2 % → 78 %）。任何降温政策若不同时**控制蔓延**，都会被新的硬化抵消。

# 4. 结论、批判性分析与改进方向（约 3 页）

## 4.1 结论

本项目完成了任务书的要求：用本学期两个模块（矢量 + 栅格），在不使用气象数据、不使用现成图层的前提下，为上法兰西大区一个市镇构建**热浪敏感性空间指标**。

方法建立在一个简单而稳健的想法上：**让地区变热的因素与让地区变凉的因素，都可以表达为随距离衰减的强度场**。核密度把这一想法转化为可计算的形式，AMC 则把三个不同单位的场聚合为单一、可制图的指数。

结果是收敛且可解释的：

- **建筑**是主导因子（最大 0.0619，均值 0.00754）；
- **植被**是真实但破碎的平衡项（最大 0.0190）；
- **水体**降温强烈但局地（最大 0.00113）；
- 综合图呈现出**东西对立**：工业-港口核心过热，沙丘与农业边缘较凉；
- 地区**结构上敏感**：78 % 人工化，植被合计仅 6.2 %，且人工化仍在上升。

操作性结论有两条：

1. **首要目标不是舒适度，而是保护人。** 应优先处理的是同时具备**强物理暴露**与**脆弱人群**的区域——而这两个维度只是部分重合。
2. **"植被"是地方政府短期内唯一真正可动的杠杆。** 因此应把它集中投放在效果最大的地方：密集街区、成片连续，而非分散的微型空间。

## 4.2 对工作的批判性分析

**做得好的地方**

- **研究对象的选择有论证**：敦刻尔克既满足题目约束，又提供了多样情境（密集中心、工业、滨海、圩田），使分析有层次而不是单一图景。
- **数据质量与体量**：43 912 栋建筑、1 131 个植被区、626 处水面、42 个 IRIS 用电单元——基础扎实，且**全部为原始数据**，符合禁止使用现成图层的要求。
- **处理链的规范化**：使用地理数据库（`EffetDataBase.gdb`）与明确的图层命名（`BatiKer1`、`VegeKer2`、`EauEffet`、`EffetEns`），使工作**可复现**、可被第三方读懂——这是学生作业中常被忽视的优点。
- **在 Excel 中预处理**（IRIS 连接、面积与密度计算）：数据进入 GIS 时已被规范化。
- **使用 AMC** 对因子排序，而不是隐式、无依据的相加。

**必须批判的地方**

- **网格未对齐。** 三个栅格像元分别为 35.5 m、33.5 m、44.4 m。用 `Raster Calculator` 组合会触发隐式重采样（默认最近邻），**损害小对象**——而小对象恰恰是要测量的东西（行道树、小水面）。应先确定一个参考网格（例如 25 m）并显式重采样。
- **核密度参数未记录。** 搜索半径、核函数、输出像元数均未留档。而这些参数恰恰决定了梯度形态：**没有它们，结果不可复现**。
- **权重缺少定量论证。** 权重集只有定性论证，没有做**敏感性分析**（若植被权重提到 0.45，地图会怎样？）。没有敏感性检验的 AMC 是不完整的。
- **没有验证。** 未与任何观测数据（Landsat 地表温度、气象站记录、地方反馈）对照。指数仍**未经检验**。
- **指数纯粹是物理的。** 社会维度（年龄、贫困、独居）仅通过用电量略作触及，未进入指数。地图测的是**暴露**，不是**脆弱性**。
- **缺少网络模块。** 到冷岛的步行可达性、救援通行在热浪情境下至关重要，本项目未涉及。
- **制图表达**：应遵守课程规则——标题、图例、比例尺、日期与数据来源缺一不可；数据来源须系统标注；分级方法（此处 Jenks）应说明理由。

## 4.3 改进方向

1. **技术 — 统一网格并记录参数。** 固定 25 m 网格，重采样三个栅格，把搜索半径与核函数写进参数表。用 **ArcGIS ModelBuilder** 重建流程以保证可复现。
2. **方法 — 权重敏感性分析。** 测试三组权重（建筑主导 / 植被主导 / 均等），并制图表现**排序的空间稳定性**（无论哪组权重都保持"极强"的区域 = 稳健区域）。
3. **数据 — 引入地表温度。** 一幅 Landsat 8/9 热红外影像（夏季）可用于**验证**并率定指数，且不违反"不得使用现成图层"的约束。这是从相对指数走向摄氏度估计最直接的路径。
4. **数据 — 下到街区尺度。** 使用 INSEE 200 m 方格（期中考试用过）或 IRIS，可与收入、年龄直接交叉，分辨率高于市镇整体。
5. **方法 — 网络模块。** 对每个 IRIS 计算**到最近公园/水体的步行时间**（Network Analyst），得到"**冷源可达性**"指标，与"冷源存在性"互补。
6. **方法 — 社会脆弱性。** 构建第二个指数（75 岁以上比例、能源贫困、老旧住房），用**双变量矩阵**（暴露 × 脆弱）与第一个指数交叉：这才是决策者真正需要的地图。
7. **组织 — 更明确的分工记录。** 记录谁做了什么、何时完成，使小组作业可个体化评估。
8. **成果 — 做成 6–8 张图的地图集**而非单张图：初始状态、三个梯度、综合指数、社会交叉、两个对比街区的放大图。

## C. 综合指数公式

$$S = 0{,}50\,B^{*} + 0{,}33\,(1 - V^{*}) + 0{,}17\,(1 - E^{*})$$
