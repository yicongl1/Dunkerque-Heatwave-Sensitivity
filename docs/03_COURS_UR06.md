## 1. 课程定位（CM01 明确给出的信息）

**名称**：UR06 — Géomatique（地理信息科学）
**学分定位**：UTC 本科阶段 GIS 入门与方法课，14 次 CM + TD + 一个小组项目。

## 5. 核心概念清单（备考用）

### 5.1 数据模型

| 概念 | 要点 |
|---|---|
| **Vecteur** | 点/线/面表示**离散对象**，边界精确；属性表与几何分离；拓扑关系可显式表达。适合：行政边界、道路、建筑、地块。 |
| **Raster** | 规则网格，每像元一个值；**连续场**（高程、温度、NDVI）与影像；分辨率决定精度与体量。适合：DEM、遥感、插值结果、密度面。 |
| **为什么两者都需要** | 矢量保精度与拓扑，栅格保连续性与可计算性（地图代数）；实际项目常混用（矢量→栅格→矢量）。 |

### 5.2 参考系

| 概念 | 要点 |
|---|---|
| **Géodésie（大地测量）** | 研究地球形状、大小、重力场与坐标系统的学科；产出**大地基准（datum）**。 |
| **Géoréférencement（地理配准）** | 给没有坐标的数据赋予空间坐标（控制点 + 变换），使其能与其他图层叠加。 |
| **Projection（投影）** | 把椭球面上的 3D 坐标 (λ, φ) 映射为平面坐标 (x, y) 的数学规则；必然产生变形（等角/等积/等距不可兼得）。 |
| **RGF93** | 法国 1993 **大地基准**（基于 ETRS89，与欧洲一致）。 |
| **Lambert 93** | 基于 RGF93 的**投影**（Lambert 等角圆锥投影，中央经线 3°，标准纬线 44°/49°，假东 700 000 m，假北 6 600 000 m）。**RGF93 是基准，Lambert 93 是投影**——这是最常考的区别。 |
| **Lambert zones（I–IV / CC42–CC50）** | 历史上法国分带的 Lambert；Lambert 93 为全国单带。 |

### 5.3 制图与图形符号学

| 概念 | 要点 |
|---|---|
| **变量 visuelles（Bertin）** | 位置、**形状（forme）**、**尺寸（taille）**、**明度/值（valeur）**、**纹理（texture）**、**颜色（couleur）**、**方向（orientation）**、**颗粒（grain）**。选择依据：数据的**测量尺度**（见 5.4）。 |
| **Discrétisation（分级）** | 把连续值切成类：等幅、等频、显著阈值、自然断点（Jenks）、标准差。 |
| **常见错误** | 类别过多导致不可读；产生空类；断点无意义；等幅用于强偏态数据；用色彩渐变表示**定性**数据；缺少标题/图例/比例尺/来源/日期。 |

### 5.4 测量尺度（échelles de mesure）

| 尺度 | 例子 | 图形表达 |
|---|---|---|
| **Qualitative nominale（名义）** | 建筑类别、地址、供暖类型 | 差异化颜色/形状（无序） |
| **Qualitative ordinale（顺序）** | 建筑年代等级、舒适度等级、道路等级 | 有序色阶、尺寸递增 |
| **Quantitative absolue（绝对量）** | 建筑面积、层数、人口数、建造年份（作为"时刻"） | 比例符号（尺寸）、分级色彩 |
| **Quantitative relative（相对量）** | 人口密度、百分比、增长率、人均消费 | 分级色彩/等值面（**不宜用比例符号**，否则误导为绝对量） |

> 复习稿中的关键争论：**"年份"算 ordinal 还是 quantitative absolue？** 作为**时间点**它是绝对量（可用线性轴），作为**年代区间**（如"1949–1975"）则是 ordinal。答题时应说明**按哪种理解**。

### 5.5 空间分析

| 概念 | 要点 |
|---|---|
| **Sélection géographique / attributaire** | 前者按**位置**（与某图层相交、在某距离内、在某面内），后者按**属性值**（SQL 表达式）。 |
| **Relations spatiales（矢量）** | 相邻（adjacence/touche）、包含（inclusion/contains）、相交（croisement/intersects）、重叠（overlap）、相离（disjoint）、共线（coïncidence）。 |
| **Géoprocessing** | Buffer、Clip、Intersect、Union、Dissolve、Merge、Spatial Join、Erase、Symmetrical Difference。 |
| **Opérations raster** | **locales**（逐像元，多栅格运算）、**focales**（邻域，如 3×3 均值）、**zonales**（按分区统计，如各市镇平均高程）、**globales**（整幅，如直方图、坡度总体）。 |
| **Interpolation spatiale** | IDW、kriging、TIN、spline；用于把点观测（温度、雨量）变成连续面；**没有观测数据时不能用**（只能用代理变量如 kernel density）。 |
| **Analyse diachronique（历时分析）** | 比较两个或多个时相的数据（如 CLC 1990/2000/2006/2012），识别变化的方向、幅度与位置；用于国土监测、政策评估。 |
| **Network analysis** | 网络数据集；最短路径、服务区、OD 矩阵、位置分配；要求网络具有拓扑与阻抗（长度/时间）。 |

### 5.6 决策支持与 AMC

- **Aide à la décision（决策支持）**：一种**建构主义**取向——不是给出"唯一正确答案"，而是提供工具，使多个（常常冲突的）观点能够在解决问题的过程中推进。
- **SIG + AMC 为何互补**：SIG 管理、可视化、分析**空间数据**（地图、卫星影像、地形）；AMC 把空间数据与**非空间准则**（成本、法规、可达性）整合，按多因素排序决策方案。
- **典型流程**：确定准则 → 归一化（min-max、z-score、效用函数）→ 赋权（AHP 两两比较、CR < 0.1）→ 加权求和 / OWA → 分级 → 敏感性分析。
- **实例**：工业设施选址（原料邻近度、劳动力、运输成本、环境法规）、垃圾处理设施选址、充电桩布点、救援中心选址。

### 5.7 案例与"应用型"考点

| 案例 | SIG 的作用 |
|---|---|
| **Denis Ruelland：积雪覆盖对气候变暖的敏感性模型** | 用**栅格**处理不同来源的层，**填补 MODIS/遥感积雪覆盖的 NoData**；用**插值**生成连续面；把 DEM、气温、降水栅格化后输入水文模型（SIAR + GR4J）；输出敏感性图。SIG 在此是**数据集成 + 前处理 + 制图**的平台，不是模型本身。 |
| **SDIS60 洪水救援** | 矢量：提取淹没区（高程 < 水位）→ 与建筑相交 → 按层数/人群分级 → 制图；路径优化用 **Network Analyst**。 |
| **卡马尔格再造林** | 栅格：重分类（营巢区/退化林地/荒地）→ 距离栅格（道路、住宅）→ 逻辑运算与重分类组合出三级优先级。 |
| **垃圾管理** | 主要关切：收集点布局、车辆路径、分类效果、填埋/回收设施选址、居民可达性；空间信息可通过**布点优化、路径优化、可达性分析、分类绩效的空间差异**改善分类。 |

## 6. 与项目的衔接

课程的三个模块（矢量、栅格、网络）在项目中要求**至少使用两个**。本项目用了**矢量 + 栅格**：

- **矢量**：投影统一、`Union` 融合建筑、`Feature To Point`、缓冲区、属性连接（IRIS 用电）、字段计算（面积、密度）；
- **栅格**：`Kernel Density`（三要素）、掩膜裁剪、`Raster Calculator` 加权合成、`Reclassify` 分级；
- **网络**：未使用（已在报告的"改进方向"中说明）。

这条链路把课程各部分串了起来：CM03–CM04（制图与分级）→ CM07（矢量分析）→ CM08–CM09（栅格与地图代数）→ 项目（AMC 合成）→ 期末（同样的问答与练习结构）。

## 7. 复习建议（按考试题型）

1. **背"区别"类问题**：矢量/栅格、RGF93/Lambert93、地理选择/属性选择、locales/focales/zonales/globales。这类题分值固定、答案结构化，性价比最高。
2. **练"流程题"**：给一个情景（养老院、洪水救援、再造林），能在纸上画出**输入 → 操作 → 中间结果 → 输出**的流程图，并注明每步用的工具名（法语）。A17 的第 6 题与 II 部分是同一模板。
3. **练"分级题"**：给一张属性表，判断每个字段的**测量尺度**，并选择**视觉变量**与**分级方法**。这是期中与期末都出现的高频题型。
4. **准备 AMC 的三句话**：为什么互补、怎么归一化、怎么赋权并检验。任何"决策支持"类问题都能用。
5. **地图规范**：标题、图例、比例尺、日期、来源、投影——写报告和考试画示意图时都要有。
